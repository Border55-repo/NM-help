# v0.4.0

- Ny kontinuerlig observer som leser URL, sidetittel, cooldown, innlogging,
  fengsel, CAPTCHA, penger og rank.
- Egen cooldown-parser for `mm:ss`, `hh:mm:ss` og norsk tekst.
- Work Mode-knapp i Windows-programmet og i mobilpanelet.
- Mobilvennlig kontrollpanel som kan åpnes fra telefon på samme nettverk.
- Learning Mode med prioritert selektorregister og lokal treffhistorikk.
- Automatisk pause ved CAPTCHA; brukeren løser den manuelt.
- Vedvarende Chrome-profil uten lagring av passord i konfigurasjonsfilen.
- Mer forsiktig aktivitetshåndtering: bare synlige og aktive kontroller brukes.
- Live-logg og tellere for handlinger og feil.
